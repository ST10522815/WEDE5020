# Mpho's Fashion Website

## 1. Project Overview

Mpho's Fashion is a responsive clothing website designed to promote affordable and stylish clothing for teenagers, young adults and adults.

The website provides information about the business, displays clothing products and allows visitors to make enquiries.

## 2. Website Objectives

- Promote affordable and quality fashion.
- Display available clothing products.
- Improve the customer browsing experience.
- Allow visitors to search for products.
- Provide contact and enquiry options.

## 3. Website Pages

- index.html - Home page
- about.html - Information about the business
- products.html - Product catalogue
- contact.html - Contact information and contact form

## 4. Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## 5. Website Features

- Responsive mobile and desktop layouts.
- Interactive navigation links.
- Product search functionality.
- Shopping cart counter.
- Interactive image gallery with lightbox.
- Interactive Google Maps embed.
- Enquiry form with validation.
- Contact form with validation.
- SEO title tags and meta descriptions.
- Image alternative text.

## 6. How to Run the Website

Open index.html in a web browser.

All HTML pages use the shared style.css and script.js files.

An internet connection is required for external images and the embedded map.

## 7. Deployment

The website can be published using GitHub Pages.
